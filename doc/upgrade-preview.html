B4 配置变更预览（Diff Viewer）
点"应用"前清楚知道改了什么。LuCI 自带 uci-change 数据，包装一个可读的 modal。

你即将应用 3 项变更：

network.lan
ipaddr = 192.168.1.1
ipaddr = 192.168.0.1
wireless.radio0
channel = 149
channel = auto
txpower = 20
txpower = 17
firewall.@redirect[0] · 新规则
name = HTTP to webserver
src = wan
src_dport = 80
dest_ip = 192.168.1.50
修改 LAN IP 后你的浏览器将断开连接。 你需要用新地址 http://192.168.1.1 重新访问。
